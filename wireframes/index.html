Screen 05 / 07

Risk and anomaly board

Task
Show deterministic risk indicators and anomaly flags computed from the same evidence record, each closed by a named human disposition.
Primary action

Error / empty state

Mobile collapse
Stack indicator cards one per row; keep each flag card whole with its disposition form directly beneath it.

Evidence receipt
